**_Ajout img dans gallerie_**

1. Dans LR, exporter les images avec "Bureau-JPEG-640PX-site web_small"
2. Placer les photos dans le dossier "Small" de la bonne galerie (ex. "src/img/paysages/Small/"), nommées img_1.webp, img_2.webp…
3. Dans le fichier translations.js, incrémenter le nombre de nouvelles photos en fonction des ajouts
4. Pousser le code en ligne
